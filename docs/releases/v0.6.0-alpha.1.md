# 0.6.0-alpha.1 — local speech development preview

Status: **awaiting further development; source preview, not a production installer**.
Published on the fork's `codex/0.6.0-preview` branch. No stable updater channel or
production installer is promoted by this branch push.

## Changes

- Adds opt-in local CPU speech recognition: Whisper base/small Q5_1 and Qwen3-ASR
  0.6B INT8, with explicit launchers and pinned model downloads.
- Retains the upstream UI, audio capture, settings and translation pipeline.
- Keeps translation in the gateway (the configured Grok model); raw audio is not
  uploaded in local mode. Qwen translation cost comparisons are not implemented.
- Uses bounded queues, a persistent model shared across streams and a request
  watchdog. Default builds still use the original cloud STT path.
- Python discovery skips native tests when optional model/build assets are absent;
  local-mode Rust tests now run in the verification workflow.
- Fixes premature UI readiness when Silero loads before local ASR. The existing
  recovery button now also retries local model initialization.
- Fixes Portable Windows version resources to accept prerelease semantic versions.

## Verification before push

Windows local checks passed: 100 local-mode Rust tests, 93 default-mode Rust tests
(3 environment-dependent tests ignored in each), 14 Portable tests, 15 gateway
tests, 17 Python tests including native Whisper, 120 frontend tests and 4 tooling
tests. Version consistency, frontend build/type check and the local-STT Tauri
desktop build also passed. Some unchanged suites were run during the immediately
preceding handoff review. GitHub CI results are separate from these local checks.
Docker/clean-machine installer and live gameplay end-to-end tests were not run.

## Known limitations

- Whisper base has significant Thai transcription errors. Small uses less RAM
  than Qwen but is slower on the measured CPU. See [measurements](../whisper-preview.md).
- Local recognition does not expose the cloud STT confidence scores/filter.
- The debug preview requires source checkout, tools and separate model setup.
  Native CPU build requires AVX2. Local-STT release packaging is blocked deliberately.
- If the launcher host is forcibly terminated, its gateway can remain on port
  18080. The launcher refuses to kill an unknown listener; close the old preview
  or inspect the port owner before restarting.
- Silero still loads PyTorch; WebView memory optimization is not part of this version.
- No guarantee of a sub-500 MB total footprint, $30/month at 500 users, or production
  readiness. Live gameplay quality, fresh-machine installation and packaged updates
  require further testing.

Start with the [developer handoff](../local-stt-handoff.md), including setup,
architecture, protocol and verification commands. Supply your own gateway key;
credentials and local usage data are not committed.
